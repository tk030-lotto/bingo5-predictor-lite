# ビンゴ5予想システムライト (BINGO5_PREDICTOR_LIGHT)

> **🌐 ライブデプロイ (Web公開URL)**: [https://tk030-lotto.github.io/bingo5-predictor-lite/](https://tk030-lotto.github.io/bingo5-predictor-lite/)

本プロジェクトは、過去の当選結果データを基に、JavaScriptを用いた多重指標（位置別EMA期待値、NPMI共起シナジー、合計値理論、奇偶・高低バランス、隣接差5）を用いて、期待値の高い組み合わせを厳選・分析する静的ウェブアプリケーション（シングルページアプリケーション）です。

---

## 📁 フォルダ構成とファイル構成

*   **[index.html](index.html)**:
    *   システム本体（3x3グリッド画面表示、手動排除コンソール、予測エンジン、バックテスト検証、インポート画面）
    *   プレミアムなUIデザイン（ダークテーマ、ガラスモーフィズム、Outfitフォント、ゴールド/パープルネオングロー）
*   **[bingo5_data.js](bingo5_data.js)**:
    *   ビンゴ5の過去の当選結果（全履歴）を格納するデータファイル。
*   **[update_data.py](update_data.py)**:
    *   `loto-life.net` から最新のビンゴ5CSVデータをダウンロードし、`bingo5_data.js` を更新する自動同期Pythonスクリプト。
*   **README.md** (本ファイル): 本ツールの利用手順および仕様書

## 🔮 搭載されている解析指標とロジック

本ツールはブラウザ上でのリアルタイムな全探索（5<sup>8</sup> = 390,625 通りの組み合わせすべてを検証）を通じて、生存した組み合わせに対して以下の指標を用いて合議スコアリングを行い、上位5点を厳選します。

1.  **位置別EMA期待値 (span=8)**
    *   各マスの数字（5択）について、直近40回の出目傾向を基に指数平滑移動平均を用いて出現確率を計算。
    *   期待値の高い数字は「排除ボード」上で自動的にハイライト（紫ボーダー）表示されます。
2.  **NPMI共起シナジー (共起確率)**
    *   過去データにおけるすべての数字ペアの共起度（同時に出現した確率）をNPMI（正規化相互情報量）により測定。
    *   組み合わせ全体の平均シナジースコアを計算し、数字の相乗効果を評価します。
3.  **合計値理論 (Sum Theory)**
    *   8つの数字の合計値（理論平均：164）の乖離度を判定。推奨デフォルトレンジ（`144 〜 184`）をフィルターできます。
4.  **奇偶バランス (Parity)**
    *   8つのマスから選ばれた数字のうち、奇数の個数（推奨: 3, 4, 5個）をフィルターできます。
5.  **高低バランス (High/Low)**
    *   各マスの相対値（1,2がSmall、4,5がBig、3がMid）の分布を評価。Small/Bigの個数が推奨（2〜4個）の範囲内であるかフィルターできます。
6.  **隣接差5ペア (Diff5)**
    *   隣り合うマス同士（配列インデックス順）で、差がちょうど5（相対値が同じ）になるペアの数を評価し、スコアに加点します。

## 🚀 使い方と運用手順

### 1. アプリケーションの起動
*   [index.html](index.html) をブラウザ（Chrome, Edgeなど）で直接ダブルクリックして開くだけで起動します。ローカルサーバーやインストールの必要はありません。
*   起動時に初回のみ利用規約・免責事項の同意画面が表示されます。

### 2. データの更新方法（最新回の追加）
以下のいずれかの方法で過去データを最新に維持できます。

*   **自動更新スクリプト (推奨)**:
    *   PowerShellまたはコマンドプロンプトを開き、本フォルダで以下を実行します。
        ```bash
        python update_data.py
        ```
    *   自動的に `loto-life.net` から最新CSVをダウンロード・パースし、`bingo5_data.js` を書き換えます。
    *   完了後、ブラウザで [index.html](index.html) をリロードしてください。
*   **画面からの手動インポート**:
    *   画面右下の「データ入力」ボタンを押し、回号、抽選日、当選番号8つを手動で登録、またはCSV/コピペ形式で一括インポートできます。

### 3. 解析＆予想の実行
1.  **排除コンソール**:
    *   3x3の排除ボードから、次回出そうにない不要な数字をタップして排除（赤・取消線）します。
2.  **多重指標フィルター設定**:
    *   アコーディオンを開き、合計値や奇偶バランスなどの条件を設定します（基本はデフォルトの黄金比率が設定されています）。
3.  **予想生成**:
    *   「合議解析 ＆ 予想生成」ボタンを押すと、生存した買い目の統計データと、上位5点の厳選予想が表示されます。
    *   厳選予想カードの3x3ミニボードにて、**直近回の当選番号と一致しているマスがゴールドに発光表示**され、直近回とどれだけ成立ラインが被っているかが視覚的に一目でわかります。

### 4. 過去検証 (バックテスト)
*   「検証バックテスト」タブを開き、検証回数（例: 直近30回）を入力して「検証実行」を押すと、その回の前日までの過去データを用いてシミュレーションを行い、生存プールの中で当選数字を位置別にどれだけ捕捉できていたか（位置別捕捉率： 8マス全て捕捉できた回の割合、および平均包含率： 8マス中平均）および厳選5点で平均何ラインがビンゴ成立したかを高速に検証しビジュアライズします。

## 💡 実用的な運用のコツ（サバイバー攻略の極意）

初期状態（手動排除なし）では、位置別捕捉率はデフォルト設定下で内蔵データの全回において各マスの全ての数字がプールに生存するため、指標による差が現れません（指標が「当選組合せがプールに含まれているか」を示すものではない点に注意してください）。一方で生存組み合わせ数が約16万通りと広いため、そのままでは厳選5点がピンポイントで的中する確率は低くなります。

本ツールの価値を最大限に高めるため、以下の手順での運用を強く推奨します。

### 🎯 EMAを用いた「手動排除」のステップ
1.  **期待値の低い数字の間引き**:
    *   3x3排除ボードで、各マスに表示されている「位置別期待値EMA（%）」を確認します。
    *   **期待値が極端に低い数字（例: 0%〜8%前後の、直近で出現する勢いがない数字）**を、各マスから手動で1〜2個タップして排除（赤・取消線）状態にします。
2.  **組み合わせ数の劇的圧縮**:
    *   仮に各マスから期待値の低い数字を2個ずつ排除すると、各マスの候補数は5個から3個になります。
    *   この場合、総組み合わせ数は $3^8 = 6,561$ 通り（初期値39万通りのわずか **1.6%**）にまで激減します。
3.  **高密度な厳選予想の生成**:
    *   この状態で「合議解析 ＆ 予想生成」を実行することで、極限まで濃縮された候補群から上位5点が抽出され、ストレートや高ラインのビンゴ期待値が爆発的に向上します。

> [!WARNING]
> 1つのマスで5つの数字すべてを排除してしまうと、組み合わせが成立しなくなり解析を実行できません。各マスに最低1つ以上の数字は生存させてください。

## 🔒 外部通信について

*   **アクセス解析**: Cloudflare Web Analytics（ページ閲覧の統計把握のため、閲覧情報が Cloudflare に送信されます）
*   **フォント**: Google Fonts（フォントファイル取得時に Google へ通信が発生します）
*   **データ取得**: ページ読み込み時に自動的に、および「最新結果を自動同期」ボタンを押した場合に、ロトデータハブ（`lotto-data-hub` の JSON）から最新の当選データを取得します（利用者の情報は送信しません）
*   上記以外に、ツールが利用者の情報を外部へ送信する経路はありません
